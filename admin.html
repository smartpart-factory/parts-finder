🛠️ จัดการระบบ

รหัส / ชื่อเครื่องจักรคงเหลือขั้นต่ำตำแหน่งสถานะ
• แก้ไขที่นี่แล้วทุกหน้า (เช็คของ ค้นหา บอท) เปลี่ยนตามทันที · ข้อมูลเก็บในระบบกลาง ทุกเครื่องเห็นชุดเดียวกัน (ผู้ดูแลระบบ ควรกด "สำรองข้อมูลทั้งระบบ" เก็บไว้เป็นระยะ)
• เมื่อเริ่มแก้ผ่านหน้านี้ ข้อมูลจะใช้แทนรายการใน data.js (กด "รีเซ็ตอะไหล่" เพื่อกลับไปใช้ data.js)
🏭 โมเดล 3D ของคลังจริง (ไม่บังคับ)
วางไฟล์ .glb ในโฟลเดอร์ models ข้างๆ index.html แล้วพิมพ์ path ที่นี่ เช่น models/warehouse.glb · ต้องเปิดเว็บผ่าน Live Server (เปิดไฟล์ตรงๆ จะโหลดโมเดลไม่ได้) · เว้นว่างไว้ = ใช้ชั้นวางกล่องจำลอง
📐 เปิดโหมดหาพิกัดใน 3D
🗄️ ผังชั้นวางดูผลใน 3D
ชื่อชั้นวางตำแหน่ง xตำแหน่ง zกว้างลึกสูงจำนวนชั้น
• x = ซ้าย(−)/ขวา(+), z = ลึกเข้าไปในคลัง(−) / ใกล้ประตู(+) · ประตูอยู่ที่ x=0, z=8.7 · ชั้นที่ 1 อยู่ล่างสุด
• ชื่อชั้นวางที่มีอยู่แล้วเปลี่ยนไม่ได้ (เพื่อไม่ให้อะไหล่ที่อ้างถึงหลุด) ถ้าต้องการเปลี่ยน ให้เพิ่มชื่อใหม่แล้วย้ายอะไหล่ไป
• อนาคต: อะไหล่แต่ละชิ้นใส่ไฟล์โมเดล 3D ของตัวเองได้ (ช่อง "ไฟล์โมเดล 3D ของอะไหล่" ในฟอร์มแก้ไขอะไหล่) และระบุพิกัดเฉพาะได้ผ่านข้อมูล pos:[x,y,z]
• เปลี่ยนชื่อเครื่องจักร: อะไหล่ที่ผูกกับชื่อเดิมจะเปลี่ยนตามให้อัตโนมัติ · ลบเครื่องจักร: จะถูกเอาออกจากอะไหล่ทุกรายการ (ตัวอะไหล่ไม่ถูกลบ)
• รูปจะแสดงที่การ์ดบนหน้าหน้าหลัก · ถ้าไม่ใส่รูป จะใช้ไฟล์ images/ชื่อ.jpg หรือภาพวาดแทน
ชื่อผู้ใช้ / ชื่อที่แสดงบทบาทสถานะสร้างเมื่อ
• ผู้ดูแลระบบ: ทำได้ทุกอย่าง รวมสร้างผู้ใช้ รีเซ็ตรหัสผ่าน และเปลี่ยนบทบาท
• ช่าง Day time: เห็นและทำได้เหมือน ผู้ดูแลระบบ (จัดการอะไหล่ ผังคลัง อนุมัติคำขอ รายงาน สำรอง/นำเข้าข้อมูล) แต่สร้างผู้ใช้ รีเซ็ตรหัสผ่าน และเปลี่ยนบทบาทไม่ได้ ปิด/เปิดใช้งานได้เฉพาะบัญชี User และลบผู้ใช้ไม่ได้
• User: ดู ค้นหา และสร้างคำขอของตัวเอง (เห็นเฉพาะคำขอของตัวเอง)
• ไม่สามารถลบ ปิด หรือลดสิทธิ์บัญชีของตัวเอง และต้องเหลือ ผู้ดูแลระบบ ที่ใช้งานอยู่อย่างน้อย 1 คน
